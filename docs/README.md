## 推荐阅读顺序

- **30 秒速览路径：** `00 → 09`，先看项目摘要，再看结果与个人贡献。
- **完整故事路径：** `00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09`，按项目推进顺序了解从发现到复盘的全过程。
- **技术深挖路径：** `05 → 06 → 10`，聚焦 AI 设计、模型验证和系统接口。
