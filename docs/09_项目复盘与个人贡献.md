# 项目复盘与个人贡献

## 1. 项目核心成果回顾

芸析智农从农业生产中的“数据分散、诊断依赖经验、建议难执行”出发，完成了**自研监测终端、鸿蒙原生应用与多模态AI诊断**的初步闭环。目前已跑通“传感器采集—4G传输—OneNet接收—应用展示—AI分析—建议生成—多端流转—安全存证”全流程，并完成手机、Web与PC端协同演示。

在校内功能验证中，系统端到端任务完成率达到**98.7%**，平均完成时间为**4.67秒**，误操作率为**1.3%**；LoRA微调后的Qwen2.5-VL-3B域内病害识别准确率超过**96.0%**。项目获2026年度大学生创新训练计划省级立项，应用已申请软件著作权，并获得鸿蒙生态前端技术峰会“最具温度设计奖”及第十五届“挑战杯”校级三等奖。

## 2. 我的角色与核心贡献

我是项目负责人何幸仪，在7人团队中同时承担产品统筹与后端/算法开发工作。我的核心贡献可以概括为四个维度：

- **需求定义与架构选型**：将项目从“农业识别应用”明确为“感知—决策—执行—溯源”的辅助决策平台，梳理农户、合作社和农技机构的差异化需求；推动采用多模态融合、RAG知识增强及云端疑难复核，避免只依赖单一图像结论。
- **项目管理与跨团队协同**：拆解硬件、鸿蒙前端、后端、模型和文案的依赖关系，以端到端链路作为共同验收标准；通过阶段评审、问题清单和接口约定协调进度，减少“单模块完成、整体无法演示”的风险。
- **后端与算法工程**：参与模型调参、数据处理和推理流程优化，搭建终端数据接入、任务路由、模型调用、SSE回传及结果存储链路；根据算力与稳定性要求，将模型推理迁移至优云智算GPU 4090。
- **申报与外部表达**：负责项目计划书、阶段材料、路演逻辑和答辩统筹，将技术参数转换为用户价值、业务闭环与可验证指标，支撑省级立项、竞赛和软件著作权申请。

## 3. 关键挑战与解决思路（STAR）

### 挑战一：硬件数据到应用端存在延迟与状态不同步

- **Situation**：硬件、网络与应用由不同成员并行开发，早期出现传感器已上报但前端未更新、4G短暂断线后数据重复，以及不同模块时间戳不一致的问题。
- **Task**：我的目标不是单独修复某个接口，而是建立可定位、可重试的完整数据链路，保证演示和后续诊断使用同一份可信数据。
- **Action**：团队统一设备ID、字段格式与时间戳规则，通过OneNet接收数据，并使用InfluxDB存储时序记录；后端增加数据校验、重复数据过滤、设备心跳和最后在线时间，硬件侧增加4G重连，前端明确展示数据更新时间与离线状态。我负责协调接口约定、联调顺序和问题归因。
- **Result**：终端采集、云端接收和应用展示能够连续联动，硬件掉线不再被误认为正常数据，端到端链路具备重复演示和问题追踪能力。

### 挑战二：模型效果、算力限制与响应速度难以同时满足

- **Situation**：原有端侧设备难以稳定承载视觉语言模型的持续推理，而完全依赖大型闭源API又会带来费用、数据边界和调用稳定性问题。
- **Task**：在准确率、时延、成本和数据控制之间寻找当前阶段可落地的平衡，并为后续迭代保留扩展空间。
- **Action**：选择参数规模约3.75B的Qwen2.5-VL-3B，通过LoRA进行领域微调，将推理服务迁移至优云智算GPU 4090；后端以任务路由统一模型调用，常规样本由微调模型处理。同时记录模型版本、耗时与复核结果，为后续评估和增量训练提供依据。
- **Result**：域内识别准确率超过96.0%，校内测试的平均端到端完成时间为4.67秒。

## 4. 项目不足与反思

当前成果仍处于校园小试阶段。现有准确率主要反映域内数据表现，尚未充分覆盖不同地域、季节、作物品种及复杂光照；节水30%、节肥25%和病虫害损失降低等业务目标仍需真实基地对照实验验证。自研终端使用基础传感器，工业环境下的防水、续航、标定和长期稳定性尚未验证；

下一阶段应优先进入少量真实地块，而不是继续堆叠功能：建立Golden Set与Bad Case机制，扩展多作物样本；引入工业级硬件测试和设备运维指标；通过对照组验证建议效果，并明确高风险场景的人工复核与责任流程。

## 5. 个人成长与AI PM能力沉淀

这个项目让我认识到，AI产品经理的价值不只是提出模型需求，而是管理模型的不确定性。我学会了用业务任务完成率、人工复核率和建议采纳率评价AI，而非只看准确率；也理解了数据飞轮必须建立在高质量反馈、人工确认和版本回归之上。

同时，我提升了跨算法、硬件、后端和鸿蒙开发的沟通能力：把技术约束翻译为产品边界，把用户问题拆成可验收任务，并在进度压力下坚持风险透明。对我而言，最重要的沉淀是形成了一个判断原则：**优秀的AI产品不是让模型替用户做所有决定，而是在正确的环节提供足够可信、可执行且可追踪的帮助。**
