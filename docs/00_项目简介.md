# 芸析智农——鸿蒙原生多模态人工智能智慧农业诊断平台

## 一句话介绍

> **芸析智农是一款面向农户、家庭农场、合作社及农业企业的智慧农业辅助决策平台，通过“自研监测终端 + 鸿蒙多端应用 + 多模态AI诊断”，帮助用户更早发现生产风险，并获得可理解、可执行、可追溯的农事建议。**

## 产品背景与痛点

农业生产正在从“经验驱动”向“数据驱动”转型，但一线用户仍面临显著的信息与决策断层：水、肥、药利用率不足40%，造成生产资料浪费；病虫害发现依赖人工巡田，识别滞后导致年均损失 **超2000万吨** ；传感器、图像和农事记录分散在不同系统，难以形成连续、可信的生产档案。

现有方案往往只解决单点监测或病害识别问题，缺少从风险发现到建议执行的完整链路。芸析智农的产品价值并非简单“识别一张病叶图片”，而是将环境数据、作物图像与农业知识转化为及时、可执行的生产建议，降低专业诊断门槛和试错成本，提升农业资源利用效率与生产管理的标准化程度。

## 产品定位与核心功能

芸析智农定位为**软硬件一体化的农业生产辅助决策平台**，由自研农业监测终端、鸿蒙原生应用及AI诊断服务组成。

- **设备接入与实时监测**：通过多传感器及4G通信采集环境与生产数据；
- **多模态智能诊断**：融合病害图像、传感器指标及用户描述，识别潜在风险；
- **风险提示与生产建议**：生成病虫害防治、水肥管理等可解释建议；
- **多端协同管理**：支持手机、Web、PC三端查看设备、地块与诊断记录；
- **安全存证与农产品溯源**：沉淀可信生产档案，为过程追踪和质量证明提供依据。

基于HarmonyOS 6的分布式能力，平台可实现设备与多端应用之间的高效协同，分布式软总线时延约8毫秒。

## AI技术架构与策略

在AI方案设计上，项目采用**端云协同、多模态融合与RAG知识增强**架构，在准确率、响应速度、成本和隐私之间取得平衡。

端侧由**优云智算云端GPU4090**承载经**LoRA微调**的**Qwen2.5-VL-3B模型**，实现0.15—1.23秒的本地推理，域内病害识别准确率超过96.0%。高频、基础识别任务优先在本地完成，以降低网络依赖和云端调用成本；复杂或低置信度案例再交由云端大模型深度复核。

诊断过程并非依赖单一模型判断，而是并发融合**视觉识别、传感器数据分析和RAG植物知识库检索**三路信息，降低仅凭图像产生误判或建议泛化的问题。数据侧依托Device Security Kit及国密算法完成安全存证，在优先本地推理的同时，保障农业生产数据的隐私性与可追溯性。

## 业务闭环与商业化

产品围绕“**感知—决策—执行—反馈—溯源**”构建业务闭环：终端持续感知生产环境，AI识别异常并生成建议，用户执行后反馈结果，系统进一步沉淀诊断与农事记录，形成可复用的生产知识和可信溯源档案。

商业模式规划为“**硬件销售 + 平台订阅 + 专业服务**”：通过监测终端完成用户切入，以设备管理、AI诊断和数据分析订阅形成持续收入，并面向合作社、种植基地及农业企业提供部署、运维和定制化农技服务。

## 产品边界与当前阶段

芸析智农的定位是**农业生产辅助决策工具**，AI输出用于风险提示和建议参考，不替代农技人员的现场判断与最终结论。对于高风险用药、复杂病害及低置信度结果，产品应明确提示用户进行人工复核。

目前项目已完成软硬件开发与系统对接，处于**校园小试及功能验证阶段**，尚未经过大规模真实农业场景验证。项目已申请软件著作权并获得大学生创新创业训练计划省级立项。下一阶段将重点验证跨作物、跨地域的模型泛化能力、建议执行效果及规模化部署成本，以真实生产数据推动产品持续迭代。
