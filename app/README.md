
# 芸析

芸析是一款面向种植场景的鸿蒙原生智慧农业应用，连接种植者、自研监测终端与多模态 AI 诊断服务，帮助用户把环境监测和作物识别结果转成可执行、可追踪的种植任务。

- **设计稿链接：** https://pixso.cn/app/design/GSp4PGXB6jx3L8a7BNWjOw?file_type=10&icon_type=1&page-id=0%3A1 。

## 产品体验

应用围绕“识别、计划、问答、推荐、监测、建议”六类任务组织体验：用户可提交植物图片、文字或语音描述，查看植物与病害相关诊断；也可查看监测终端采集的环境数据，并获得种植建议、每日计划和风险提醒。AI 输出用于辅助决策，不替代农技人员的专业判断。

**主要流程：**

1. **采集信息：** 拍摄植物、输入问题或语音描述；已接入的监测终端提供空气温湿度、光照和土壤温度数据。
2. **获取诊断：** 应用汇总图像、用户描述和环境信息，呈现诊断说明与相关风险。
3. **转成行动：** 将建议呈现为每日种植计划、任务或提醒，支持用户后续查看和反馈。

## 核心能力

- 植物类型与病害辅助识别
- 图文问答、语音输入与 TTS 语音播报
- 每日种植计划、适宜植物推荐和风险提醒
- 诊断记录安全存证

## 鸿蒙与 AI 能力

应用基于 ArkTS/ArkUI 开发，并集成 HarmonyOS Vision Kit 拍照识别、Speech Kit 语音输入、Notification Kit 提醒及服务卡片等能力。项目方案还包括 OrangePi AIPro 20T 端侧承载 Qwen 视觉语言模型、RAG 植物知识库辅助检索，以及对疑难样本进行进一步分析复核。

## 当前进展

- 鸿蒙应用与自研监测终端已完成开发并完成初步对接，可在校内演示端到端流程。
- 项目材料记录了一组校内功能验证数据：诊断流程由 5 步缩短为 3 步，任务完成率 98.7%，平均完成时间 4.67 秒，误操作率 1.3%。
- 应用已申请软件著作权；项目获 2026 年度大学生创新训练计划项目省级立项。
